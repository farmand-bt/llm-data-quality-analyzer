# LLM Data Quality Analyzer

A Streamlit-based tool for automated data profiling, interactive cleaning, and optional LLM-powered quality insights for CSV and Excel files.

Upload a dataset and instantly get a comprehensive quality report: missing values, duplicates, outliers, distribution analysis, type issues, correlations, and actionable recommendations. Optionally enable natural-language insights generated by an LLM (via GWDG API). After reviewing the report, apply automated cleaning actions and download the cleaned dataset.

## Features

- **Data Profiling** — per-column statistics, type inference, missing value analysis, outlier detection (IQR & Z-score), distribution analysis with normality tests, and correlation heatmap
- **Quality Scoring** — composite 0–100 score and letter grade (A–F) with a breakdown of what's affecting data quality
- **Interactive Cleaning** — remove duplicates, impute missing values, fix type mismatches, handle outliers; every step is logged and non-destructive
- **LLM Insights (optional)** — plain-English explanations of findings via GWDG API; fully optional and never sends raw data rows to the LLM
- **Export** — download the cleaned dataset as CSV or Excel

## Tech Stack

- **UI:** Streamlit
- **Data:** pandas, numpy, scipy
- **Visualizations:** Plotly
- **LLM (optional):** GWDG API via `openai` Python SDK
- **Linting:** Ruff

## Setup

```bash
git clone https://github.com/your-username/llm-data-quality-analyzer.git
cd llm-data-quality-analyzer
uv sync
```

To enable LLM insights, copy `.env.example` to `.env` and fill in your GWDG credentials:

```bash
cp .env.example .env
```

## Usage

```bash
uv run streamlit run app/app.py
# or
make run
```

Open [http://localhost:8501](http://localhost:8501), upload a CSV or Excel file, and explore the quality report.

## Development

```bash
make lint      # ruff check + format
make test      # pytest
make clean     # remove build artifacts
```
